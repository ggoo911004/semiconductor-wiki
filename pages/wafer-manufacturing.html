晶圓製造 (Wafer Manufacturing) 與長晶技術

1. 製程名稱與定義 (Process Overview)

晶圓製造是整個 IC Fab 製程的起點。從原始的石英岩出發，經過純化與長晶程序，製作出供後續微影、沉積、蝕刻與 CMP 使用的空白矽晶圓[cite: 6]。

純化核心化學反應 (Sand to Wafer)[cite: 6]：

  • SiO2 + 2C (加熱) → Si (金屬矽 MGS) + 2CO[cite: 6]
  • Si + 3HCl → SiHCl3 (三氯矽烷 TCS) + H2[cite: 6]
  • SiHCl3 + H2 → Si (電子級多晶矽 EGS) + 3HCl[cite: 6]

2. 核心機制與原理 (Core Mechanism)

將電子級多晶矽轉化為單晶矽晶棒，主要依靠以下兩種長晶技術：

柴氏拉晶法 (CZ 法, Czochralski Process)[cite: 6]

  • 目前半導體與光伏產業最普遍使用的單晶矽製造技術（市佔約 85% 以上）[cite: 6]。
  • 將電子級矽置於石英坩堝內加熱至 1415°C 融化[cite: 6]。
  • 降下單晶矽晶種接觸熔融矽，在熱穩定後緩慢拉出並旋轉，使熔融矽沿晶面生長，耗時約 48 小時[cite: 6]。

懸浮區熔法 (FZ 法, Float Zone Process)[cite: 6]

  • 不使用石英坩堝的高純度單晶成長與純化技術[cite: 6]。
  • 在氫氣環境下，使用高頻感應 (RF) 線圈將多晶矽晶棒底部加熱至 1400°C 以上熔化，並與晶種融合[cite: 6]。
  • 透過表面張力懸浮，隨著線圈緩慢上升，下方冷卻凝固成單晶結構[cite: 6]。
  • 純氫氣可完全隔絕空氣，防止與氧氣、氮氣反應[cite: 6]。

3. 比較分析 (Comparison)

單晶矽 vs 多晶矽[cite: 6]

比較項目 單晶矽 (Mono-Si)[cite: 6] 多晶矽 (Poly-Si)[cite: 6]
內部結構 晶格排列單一、完整，無明顯晶界[cite: 6] 由多個不同方向的晶粒組成，存在晶界[cite: 6]
外觀特徵 色澤均勻 (深黑色或墨黑色)，邊角常呈倒角[cite: 6] 表面帶有類似碎玻璃或雪花狀的反光紋理與色差[cite: 6]
轉換效率 較高 (太陽能板效率約 22%~23% 以上)[cite: 6] 略低 (太陽能板效率約 17%~21% 左右)[cite: 6]
製程成本 長晶製程慢、技術門檻高，成本較高[cite: 6] 鑄造製程快、技術較簡單，成本相對低廉[cite: 6]

長晶技術：CZ 法 vs FZ 法[cite: 6]

比較項目 直拉法 (CZ 法)[cite: 6] 懸浮區熔法 (FZ 法)[cite: 6]
石英坩堝 有使用[cite: 6] 無使用 (懸浮熔區)[cite: 6]
含氧量與純度 含有一定濃度的氧 (易受石英坩堝污染)[cite: 6] 極低 (幾乎無氧)[cite: 6]
電阻率 相對較低[cite: 6] 可達非常高[cite: 6]
優缺點 優點：可製作大口徑晶圓，成本低。
缺點：晶體品質較差，有雜質污染。[cite: 6]		 優點：高純度，晶體品質佳。
缺點：容易形成差排、空洞，晶片尺寸受限於表面張力通常較小。[cite: 6]

4. 應用場景 (Applications)

CZ 法拉出的大口徑晶圓，是目前一般大規模積體電路與主流半導體晶圓的首選[cite: 6]。而 FZ 法由於能做到極低含氧量與高電阻率，主要應用於高功率、高電阻率的特殊電子元件中[cite: 6]。
